## 2. Downloadable Resources & Companion Reading Architecture

### A. Printable Activity Packs (`/printables/[id]`)
1. **Letter Sound Safari**: Early phonics tracing mats, letter-sound matching, animal alphabet cards (Ages 3–5).
2. **Bedtime Routine Reward Chart**: Calming bedtime sticker tracker and 7-night reading streak goal (Ages 2–6).
3. **Story Map & Character Detective**: Narrative comprehension worksheet: beginning, middle, ending, character traits (Ages 5–8).

1. **Sleepy Fox Bedtime Reflection Journal**: 30 nightly prompts connecting story themes to daily emotions.
2. **Little Explorer Daily Reading Log**: 60-day guided reading tracker with emoji ratings and vocabulary builder.

- **Phonics & Phonemic Awareness Foundation** (Ages 3–5)

## 5. cPanel Deployment Guide (Node.js App)

If deploying to traditional cPanel hosting:
1. Open cPanel and search for **Setup Node.js App**.
2. Click **Create Application**:
   - **Node.js version**: `20.x` or `22.x`
   - **Application mode**: `Production`
   - **Application root**: `kids-website` (or directory name)
   - **Application startup file**: `server.js`
3. Clone or upload your code via **Git Version Control** (`https://github.com/zehra2/kids-1.1.git`) or **File Manager**.
4. Open cPanel **Terminal**, activate the node virtual environment, and run:
   ```bash
   npm install
   npm run build
   ```
5. Click **Restart** in the Node.js App dashboard.

## 6. Vercel Deployment Guide (Free & Recommended)

Vercel offers zero-configuration hosting tailored specifically for Next.js:
1. Visit **[vercel.com/signup](https://vercel.com/signup)** and click **Continue with GitHub**.
2. Click **Add New...** > **Project**.
3. Select your repository **`kids-1.1`** and click **Import**.
4. Click **Deploy**.
5. Your website will be live in 45 seconds at `https://kids-1-1.vercel.app` (with automatic free SSL and GitHub auto-updates).
